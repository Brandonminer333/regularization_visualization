# regularization_visualization
Easy-to-interact exploration of how minimum loss functions with regularization constraints 

### Introduction
The purpose of this project is the help build insight into how L1 and L2 regularization works, and why the LASSO regression (regularization with L1 norm) can shrink coefficient estimates to exactly zero.
